# Run evidence

The package intentionally ships without fabricated solver output. Execute the fail-closed runner once in the frozen Ubuntu/CBMC repository environment. It creates `evidence/run_1` containing the two GOTO model pairs, complete proof and cover results, inventories, source/tool identity, hashes, distinctness output, and final acceptance status.

A pre-existing `evidence/run_1` causes immediate refusal, preserving `RUNS OCCURED: 1`.
