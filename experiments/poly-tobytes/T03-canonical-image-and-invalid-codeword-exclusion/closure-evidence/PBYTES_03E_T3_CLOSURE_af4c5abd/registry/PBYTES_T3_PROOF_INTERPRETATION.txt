INDEPENDENT_BLOCK_DECODER:
W = b0 + 256*b1 + 65536*b2
even_field = W mod 4096
odd_field = W / 4096

EQUIVALENT_IMPLEMENTATION:
even_field = b0 + 256*(b1 mod 16)
odd_field = floor(b1 / 16) + 16*b2

PBYTES-T3.P1:
Every even field decoded from an actual output block is below MLKEM_Q.

PBYTES-T3.P2:
Every odd field decoded from an actual output block is below MLKEM_Q.

PBYTES-T3.P3:
For every pair of canonical fields and every pair position, a canonical
polynomial exists whose actual serialization contains the corresponding
three-byte block at that position.

PBYTES-T3.P4:
For every canonical input polynomial, every output position and every
candidate block with at least one invalid field, the actual output block
is different from that candidate block.

PBYTES-T3.P5:
The forward image direction is established by the global form of P1 and P2.
The reverse image direction is proved by decoding an arbitrary full byte
array with 256 canonical fields, serializing those decoded fields through
the real public wrapper and asserting complete 384-byte equality.
