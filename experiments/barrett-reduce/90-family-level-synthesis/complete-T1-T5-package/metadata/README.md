# BR-AF4 T1-T5 complete theorem-family evidence candidate

This package is the top-level evidence container for five independently
structured Barrett-reduction theorem families checked against the frozen
mlkem-native implementation.

Each individual theorem archive contains its harnesses, GOTO models, property
inventories, CBMC results, controls, mutations, traces, manifests and
limitations.

Start with:

1. `BR_AF4_COMPLETE_FAMILY_METADATA.txt`
2. `reporting/BR_AF4_T1_T5_EVIDENCE_SUMMARY.md`
3. `reporting/BR_AF4_T1_T5_THEOREM_LEDGER.tsv`
4. `reporting/BR_AF4_T1_T5_CLAIM_BOUNDARY.md`
5. `verdicts/`

The package is an evidence candidate pending final external forensic review
and the separate literature-novelty audit.
