# POLYCOMP-D4 evidence classification

This overlay adds the clean-room CBMC theorem family for portable-C D4 polynomial compression and decompression to the repository's existing scientific structure.

- `experiments/polycomp-d4/00-campaign-setup/`: source/native analysis, theorem registry, T1 preflight, and shared source binding references.
- `experiments/polycomp-d4/T01-compressor-refinement/`: compressor refinement, coverage, reachability, relational packing, and three mutation controls.
- `experiments/polycomp-d4/T02-decompressor-refinement/`: decompressor refinement, non-vacuity, two mutation controls, byte locality, and original-to-R2 package repair provenance.
- `experiments/polycomp-d4/T03-compressed-domain-retraction/`: real decompression/compression retraction, nibble preservation, cycle stability, and two mutation controls.
- `experiments/polycomp-d4/T04-quantizer-projection/`: codebook membership, distortion bound and witness, fixed points, idempotence, locality, reachability, and isolated mutations.
- `provenance/frozen-baseline/polycomp-d4/`: five immutable final evidence archives and sidecars.
- `upstream/mlkem-native/polycomp-d4-af4c5abd-source-binding/`: one canonical copy of the six source files embedded identically in every final package.
- `reports/campaign-overviews/polycomp-d4/`: source-derived navigation summary.
- `reports/novelty-and-prior-art/polycomp-d4/`: source-derived claim boundary.
- `provenance/polycomp-d4-classification/`: complete accounting, mapping, archive audit, hashes, and publication-safety notes.

Original run directory names are preserved below each scientific category so recorded commands, timestamps, manifests, and thesis references remain traceable.
