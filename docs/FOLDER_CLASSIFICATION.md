# Scientific folder classification

## Polynomial addition

- `00-campaign-context`: repository and production-context discovery.
- `PA01-canonical-domain`: canonical-domain exactness campaign and its V1/V2 raw runs.
- `PA02-full-signed-contract-domain`: sliced signed-domain verification.
- `PA03-unrestricted-negative-control`: unrestricted-input counterexample campaign.
- `PA04-aliasing-diagnostic`: safe and unrestricted aliasing cases.
- `PA05-production-callsites`: production call-site verification.
- `PA06-cross-parameter-replication`: ML-KEM parameter-set replication.
- `PA07-mutation-sensitivity`: mutation testing.
- `PA08-vacuity-and-boundaries`: reachability and boundary controls.
- `PA09-provenance-and-novelty`: provenance and novelty analysis.

## Polynomial subtraction

- `00-campaign-setup`: source analysis, preregistration, early harness/build development, and pre-theorem evidence.
- `T01-exact-semantics`: exact subtraction semantics, coverage/non-vacuity, mutation hardening, and VC-SR1 extension.
- `T02-relational-boundaries`: relational and boundary properties.
- `T03-cancellation-identities`: subtraction/addition cancellation identities.
- `T04-canonical-domain`: canonical input-domain theorem and invalid-domain controls.
- `T05-relational-properties`: frame, locality, noninterference, and determinism.
- `T06-callsite-integration`: production call-site, handoff, reachability, expected-failure, and mutation campaign.
