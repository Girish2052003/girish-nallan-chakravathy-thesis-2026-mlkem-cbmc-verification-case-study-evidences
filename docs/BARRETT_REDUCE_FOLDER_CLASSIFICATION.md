# Barrett-reduction evidence classification

This overlay adds the BR-AF4 `mlk_barrett_reduce` campaign to the repository's existing scientific structure.

- `experiments/barrett-reduce/00-campaign-setup/`: start states, retries, and frozen source identity.
- `experiments/barrett-reduce/T01-...` through `T05-...`: canonical raw runs, hardening/mutation controls, candidate reviews, and final forensic verdicts.
- `experiments/barrett-reduce/90-family-level-synthesis/`: partial and complete family package metadata.
- `reports/`: family summaries, theorem/control ledgers, portability notes, claim boundaries, and novelty-audit status.
- `provenance/frozen-baseline/barrett-reduce/`: immutable candidate and final theorem archives.
- `upstream/mlkem-native/barrett-reduce-af4c5abd-full-source-snapshot/`: the complete source snapshot used by BR-AF4.
- `provenance/special-git-metadata/barrett-reduce/`: the original machine-local `.git` worktree pointer, separated from publishable source.

The original run directory names are preserved below their scientific category so that recorded commands, paths, manifests, and thesis references remain traceable.
