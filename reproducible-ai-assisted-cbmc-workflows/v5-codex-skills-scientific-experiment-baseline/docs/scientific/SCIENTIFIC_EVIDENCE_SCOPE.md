# Scientific Evidence Scope

## Included evidence

1. Complete V1–V4 historical workflow snapshots and their publication manifests.
2. Historical configurations, source/specification inputs, run outputs, critic findings, build/tool records, API provenance, counterexample records, repair evidence, and evaluation artefacts.
3. Nine browseable V5 repository-scoped skill implementations.
4. Every skill contract, input/output schema, fixture, test implementation, validation report, boundary catalogue, and internal hash manifest.
6. V1–V4 run chronology, critic index, command/output index, file inventory, and archive-hash records.
7. V5 hypotheses, experimental conditions, claim ledger.

## Authority boundary

- LLM/Codex outputs are candidate semantic artefacts.
- Deterministic skills provide bounded mechanical assistance and have no semantic authority.
- CBMC provides tool evidence for the exact recorded model and command.
- Final scientific interpretation remains external to the runtime.
